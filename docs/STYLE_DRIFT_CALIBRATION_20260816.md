## 基线与留出验证

| 指标 | calibration | validation | 解释 |
|---|---:|---:|---|
| deep 对白保留中位数（成稿句数/源章句数） | 1.000 | 0.923 | 留出书仍显示闭卷方向偏低，但 3 章样本不足以把比例写成常数 |
| shallow 对白保留中位数 | 1.000 | 1.000 | 开卷在两半都保持直接引语数量 |
| deep 段均长度比中位数 | 1.227 | 1.854 | 留出书出现更长段，说明形态漂移存在且跨书方差很大 |
| shallow 段均长度比中位数 | 1.228 | 1.279 | 方向一致，但“应拆在哪里”没有唯一答案 |
| deep 句均长度比中位数 | 0.890 | 0.866 | 方向一致，仍不能推出安全的自动改句路径 |
| shallow 句均长度比中位数 | 1.000 | 0.925 | 变化较小且跨书不同，不能据此自动重写 |

命中也支持同一结论：`dialogue_ratio_drift` 在 calibration 命中 19/39、validation 命中 11/26；
但 validation 的 shallow 章对白句数中位仍为 1.00×。因此“对白字符占比偏了”不等于“台词丢了”，
按比例自动加台词或删叙述会把一个真实读数变成错误修法。`band_drift` 分别命中 28/39 与 12/26，
`para_len_drift` 命中 10/39 与 10/26；它们能指出形态不同，却不能决定该合并哪段、改写哪句。

短段成串在每章都作为 `short_run_report` 出现，这是度量覆盖，不是 65/65 条缺陷。当前 3 本的源文
p95（calibration 5.47/千字、validation 1.06/千字）不足以替代冻结的 163 本体裁基线 7.68；因此不调线。
破折号同理，本小样本源文 p95 为 0.11/0.00，不能覆盖原 163 本的 2.25。

## 真阳、可修方向与副作用

| 族 | 标定结论 | 安全处置 |
|---|---|---|
| `dialogue_halved` | 这批 0 命中，仍是零真实样本；但其前件收窄到 shallow、计划无净压缩、源章至少 4 句，源台词就在下发面 | 保留 `HARD + UNIQUE`；只允许“写回眼前已有台词”，不得扩到 deep |
| `layout_drift` | 留出集 deep 2/3、shallow 2/23 命中；命中的是可定位的“冒号提示语与引语挤在同段” | `INFO + UNIQUE`；只插入换行，不改一个字 |
| `dialogue_fewer` / `dialogue_broken` | 数量下降是真信号；既有真实返工曾为 7→11 句凭空编出台词 | `INFO + FREE`，进待人工，不进默认付费反哺 |
| `dialogue_ratio_drift` | 高命中但与句数保留明显分离；调比例可通过加台词或删叙述，副作用都触及内容 | `INFO + FREE`，只展示原始比值与人工路由 |
| `band_drift` / `para_len_drift` | calibration 与留出书都能复现形态差异；“差异”是真，是否为缺陷及断句位置不唯一 | `INFO + FREE`，人工裁决 |
| `short_run_report` | 与全章段均不是同一维，但当前只有体裁参照、没有缺陷真值 | 保持 `metric`，不生成修订指令 |

由此，自动付费修订的准入仍是 `Rule.repair == UNIQUE`。上述风格族只有 `dialogue_halved` 与
`layout_drift` 符合；其他项即使命中也只进入报告/待人工清单。这个选择由
`contracts/judges/stage5.py` 的注册表与 `revise_targets()` 的筛选共同执行，不靠文档约定。

## 修订后的双重检查

盘上只有 1 个可配对的现役修订样本（shallow ch04，人工 round 1→2）：

- `trim_regressions` 内容回归为 0；
- 对白占比 0.290→0.289、段均 28.5→28.4、句均 17.6→17.5；
- 它不是风格修订，数字基本不动是符合预期的，不拿它冒充“自动风格修复有效”。

运行时闭环现在强制同时做两件事：候选先相对旧正式稿跑内容回归；通过后仍走完整 `_write_chapter`
重算所有风格与保真判据。内容退化时只允许一次 `refresh-write` 重采样；第二次仍退化则保留旧稿，
把两份候选写入 `chNN.rejected.json`。因此“数字回到区间但内容变坏”的候选不能覆盖正式稿，
而“内容没坏但目标风格未改善”会在新一轮完整报告中继续保持命中，不会被记成已经修好。

限制：本轮没有获授权发起新的付费风格修订；结论使用现有付费产物和一个人工修订对。若将来要扩大
`UNIQUE` 范围，必须新增未参与定线的真实修订对，并同时交付内容回归与目标指标变化，不能只看数字。
