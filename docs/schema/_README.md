# 产物 schema —— 怎么读，怎么产

**本目录定的是「内容」，不是「载体」。** 有哪些字段、什么类型、哪些必填、取值面是什么——
这些与代码放哪儿无关，现在就能定死。
**载体已定：Pydantic v2**（2026-08-10 裁决，理由见仓根 `README.md`）——
但那不改变本目录的职责：**这些 `.md` 是人读的源，模型在骨架阶段照它们写，方向别搞反。**
所以下面的表里**不出现任何 Python 类型标注**，只出现「类型 / 必填 / 取值面 / 证据」。

---

## 三源合并

每个字段都过这三个来源，**对不上的地方就是发现**，不能挑一份照抄。

| 来源 | 它给什么 | 它缺什么 |
|---|---|---|
| **盘上产物** | 真实类型、真实取值面、真实规模 | **异常路径**——三本书跑得越干净，没触发的分支越多 |
| **`CONTRACTS.md`**（原型仓） | 字段语义、`[HARD]` 标注、为什么长这样 | **不是完整 schema**，它只列「有消费方或有判据」的字段 |
| **原型代码的产地** | 那些从没被触发过的字段真正会写什么 | 没有语义说明 |

## 「证据」列 —— 本目录的核心机制

它与需求文档那一列「谁在查」是同一个东西：**让「我们真的知道」与「我们只是写着」读起来不一样。**

| 取值 | 含义 |
|---|---|
| **`三源`** | 盘上观察到 + 契约写了 + 代码写了。可信度最高 |
| **`盘·码`** | 盘上有、代码有，**契约没写**。契约文档漏了它 |
| **`契·码`** | 契约有、代码有，**盘上零样本**——异常路径没被触发过。<br>**类型和取值面是从代码读出来的，不是量出来的** |
| **`⚠冲突`** | 三源说法不一致。**定契约之前必须先裁决哪个是权威** |

⚠ **「盘上 3/3」不等于「必填」，更不等于「非空」。** 已实测的反例：
`partition_report.platform` 在盘上 3 本全是 `'FQ'`，看起来像必填非空字符串——
而**全语料 163 本里有 120 本它会是 `null`**。
只按盘上产物定 schema，会定出一个在 74% 的语料上崩掉的契约。
⇒ 凡是「盘上零样本」或「盘上取值面明显偏窄」的字段，都要去**全语料**或**代码**再确认一次。

> 〔`platform` 这个字段本身已从产物里删掉（无消费方，且没有第二个平台值）。
> **例子留着**：它是本目录这套方法最干净的一次命中，与该字段还在不在无关。〕

⚠ **反过来也成立：「盘上有」不等于「该落盘」。** 定完取值面还要再问一句
**「这条信息能不能 0 成本重新算出来」**——能现算的字段落盘只是抄第二份，
而两份同源数据哪天不一致时，没人知道该信谁。
实例：`stage1/partition_report.json` 从原型的 **24 个字段瘦到 9 个**——删掉的那些
全部可由 `main_text.json` / `hook_copy.json` / 目录名 / 原文现算。
留下来的判准是**不可再生**：`source_sha1`（没有记录值就没法判「有人换过原文」）、
剔除记账（记的是一段已经被丢弃、盘上不留副本的文本，见 `stage0.md` §2.2）。

## 版本与路径注册表

产物路径字面只登记在 `contracts/artifacts.py::ARTIFACT_PATHS`；节点 `produces`、消费投影、
schema 路由与 stage 真实读写均引用该目录。路径模板由 `artifact_rel()` 展开，逐章 `nn` 统一补零两位。
`contracts/schema/__init__.py::ARTIFACT_SPECS` 只为其中的 JSON 子集叠加当前模型、schema version 与
逐版本迁移，`ARTIFACTS` 继续作为兼容读法从它派生，不再有第二张手抄路径表。

未标版本的存量 JSON 视作 v0；当前普通对象顶层带 `_schema_version`，RootModel 用
`{_schema_version,payload}` 信封。迁移只做能由旧字节证明的无损转换；缺失新语义时明确拒读，
错误必须带文件与版本。当前 Pydantic 模型不接受旧字段别名或双形状，兼容只发生在这一个读取边界。

## 反推工具

盘上那一源由一个机械反推脚本产出（0 成本、可重跑）：遍历 `Output/` 下每本书的产物，
逐路径记类型 / 出现率 / 取值面。它**只报「观察到了什么」，不推断语义**。
脚本在 `tools/derive_schema.py`。语料目录默认取本仓的兄弟目录
`../Novel_refactoring/Output`，可用 `NOVEL_OUTPUT` 覆盖。
⚠ **找不到目录时它显式终态**，不会静默产出一份「所有字段都零样本」的 schema——
那种产物与真跑过的长得一模一样。

> ### ⚠ 有「人修完再落盘」这条路的层，`_rounds/` 归档**必须一起反推**
>
> 正式产物是**修完之后**的状态，它会把「修之前才出现的取值」整个抹掉。
> 実测（stage7）：`residual[].confidence` 在 3 份正式产物上是**单值 `low`**（19/19），
> 而 8 份归档里有 **35 条 `high`**——高置信的那些早就被人勾选、走人工补充修掉了。
> **只反推正式产物，会定出一个把 `high` 当成零样本分支的 schema。**
> 〔stage6 那次把归档加进来只确认了「归档与正式同形」；stage7 这次第一次**改变了取值面**。〕
