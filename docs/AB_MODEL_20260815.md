# 模型×思考 2×2 对比实验（2026-08-15）

**目的**：为流水线选定 `DEEPSEEK_MODEL` × `DEEPSEEK_THINKING` 的默认组合。
**四臂**：deepseek-v4-pro / deepseek-v4-flash × 思考开（现行 LADDER，high 起步带降档）/ 关思考（单档 `('low', False)`，`NOTHINK_RUNGS`）。
**样本**：主样本《前任赘夫逃跑后》sid 2022040243025528636（1.06 万字/19 章）四臂全链；复核样本《我教夫人斗渣夫》sid 2068327305420748057（1.9 万字/26 章）过闸二臂全链。
**基础设施**：思考开关 `DEEPSEEK_THINKING`（commit 9f1a245）、跨臂对比读数器 `tools/ab_compare.py`（commit bac5021）。四臂四 base 四缓存目录 + 判官缓存 ×4，全部冷启动、互不复用（`outputs/ab_model_20260815/`）。

## 一、设计与免责声明

- **测量口径恒定**：两个语义判官节点（stage5.semantic / stage6.semantic）在所有臂统一用 pro+满思考跑（按进程环境变量切换），判官成本与生成成本在账本按 node 分账。
- **决策规则**：先质量闸（HARD 残留、语义泄底、成书三查、inbox 人工负担、修复轮数不得劣于 pro_think 基线），过闸者比钱（当日牌价折算）与墙钟；**单次跑不做质量细排名**——上一轮 prompt 三臂 A/B 的教训是非同种子配对采样不可归因（docs/E2E_VALIDATION_20260813.md:270），LESSONS 第 13 条要求无 ground truth 时只报分布不强行定线。
- **修复方针**：HARD·remediation=llm → 定向付费重跑（`--chapters` 自动 refresh）；global 级闸无定向 flag 时删除本臂对应缓存条目后同参数重跑（等价强制重采样），上限三轮；mechanical/human 且可用**决策文件**表达的 → `--apply-edit`（agent 写路径白名单内）；每次干预计入臂档案，修复轮数本身是质量指标。
- **成本口径**：账本只记 token 事实（Q-10 不存价格）；折钱只在本报告内，用带日期费率表；input 全按未命中价=上界（服务端上下文缓存命中份额在账本不可见）；completion 含 reasoning（DeepSeek 计费口径）。
- **墙钟口径**：账本 span 分段（>600s 缺口切段）为主，Σlatency 并发下高估仅作对照；判官一致性轮与 flash 复核书尾段曾并行（用户要求提速），二者墙钟互染，已标注。

## 二、探针（2026-08-15，3 发，max_tokens=2048，不走缓存不入账本）

| 探针 | 结果 |
|---|---|
| pro + (high, True) | ✅ 对照正常，reasoning_tokens 116 |
| flash + (high, True) | ✅ **flash 接受 reasoning_effort + thinking 参数且真产思考**（reasoning_tokens 39），2×2 四臂成立 |

附带观察：关思考时 prompt 模板少 ~79 token（26 vs 105，同一消息体）；flash 探针延迟 1.0-1.6s vs pro 6.3s。
探针花费：合计 prompt 236 / completion 203 token（手工记账，双模型混计）。

## 三、臂级裁定（主样本）

| 臂 | 结果 | 干预记录 |
|---|---|---|
| **pro_think** | ✅ 成书 19 章 / 10,560 字 / 残留 0 | 1 付费修复（s2 ch4 区间重叠）+ 1 决策文件（s7 周家→顾家/陈家→沈家） |
| **flash_think** | ✅ 成书 19 章 / 10,916 字 / 残留 0 | 1 付费修复（s2 ch4 拍过粗）+ **2** 决策文件（s4 写法词「张力」入计划、s7 悬空姓氏映射+周家→谢家） |
| **pro_nothink** | ❌ **stage2.global 三轮不过** | r1 secret_setup_order 闸；r2/r3 必需列表为空（too_short），单档无降级，exit 70 |
| **flash_nothink** | ❌ **stage2.global 三轮不过** | r1 role_leaks_fate+secret_setup_order 闸；r2 too_short；r3 secret_setup_order 闸 |

**思考轴结论（决定性）**：关思考在全书级结构化抽取上**双模型系统性失败**——维持秘密「先埋后揭」的全局排序、填满 17K 字 JSON 的全部必需列表，依赖推理预算；单档 `('low', False)` 连降级空间都没有。三轮×两臂共六次采样零成功，非抖动。⇒ **`DEEPSEEK_THINKING` 默认必须保持 `on`**。

附带发现（登记待办，不在本实验范围）：
1. `LlmFailed`（阶梯耗尽）落 exit 70（未捕获异常）而非 exit 2（显式终态）——语义上它是「模型给不出可用产出」的终态，不是 bug 崩溃。
2. stage6.hook 的 `hook_para_sep` HARD 命中时判据自述「归一化应该已经修掉它了，这条亮了说明归一没跑或坏了」——复核书 pro 臂实测三候选全单段墙文被拦，疑似归一化缺口。
3. `--apply-edit` 的相对路径按 cwd 解析而报错文案按书目录语义写，易误导（实测踩到，绝对路径可绕）。

## 四、复核样本（1.9 万字/26 章）

| 臂 | 结果 | 干预记录 |
|---|---|---|
| **pro_think** | ✅ 成书 26 章 / 18,639 字 / 残留 0 | 1 付费修复（s2 ch5 拍过粗+ch26 编造锚点）+ 1 付费重采样（s6 三候选全单段墙文被 hook_para_sep 拦）+ 1 决策文件（s7 谢家→程家×29 等 38 处家族名残留 + kept 夹已改名） |
| **flash_think** | ❌ **stage6.hook 三轮不过，终止未成书** | s2.global 一轮被拦（address_bare_pronoun+secret_setup_order，58s 浅思考出稿）重采样后过（517s）；s2 ch5 拍过粗定向重跑（与 pro 同章同读数 422字/拍——该章本身难切）；s4 **第二次**泄写法词（决策文件收口）；写作/验收正常（1.02×）；s6.hook 三轮：r1 深思考 59s 单换行墙文、r2 **浅思考 7s/reasoning=10** 单换行、r3 深思考 98s/reasoning=8654 **零换行单行体**——三轮全不中该书的空行分段体裁，按预注册三轮上限终止 |

**公平性 caveat**：`hook_para_sep` 是归一化缺口（判据自述应由归一化机械修掉），本书双模型 6 次采样全部踩中，pro 第二采样通过含运气成分。但同一缺口下 pro 2 采样收口、flash 3 采样不收口且伴随浅思考发作，稳健性差距仍然成立。

**flash 的可复现习惯**（跨两本书重现）：① 计划自由文本里掺写法指令词（两本书各中一次 `style_words`，pro 零次）；② 全书级抽取偶发「浅思考」快速出稿导致排序类 HARD（复核书 58s 被拦 vs 重采样 517s 通过）。两者都能以既有修复机制低成本收口，但意味着 flash 作生成模型时修复回路期望次数更高。

## 六、判官一致性（flash+满思考自任判官，冻结副本 + 空缓存强制重采样）

- **stage5.semantic：直接失败。** ch11 claims 抽取四档阶梯全灭——high 档答案流丢失（content 空），medium/low/low-nothink 三档全部**编造非逐字证据**（判官纪律要求 evidence 是正文连续子串），`LlmFailed`。78 次 attempt 后死于单章。**flash 无法胜任逐字证据纪律下的语义判官。**
- **stage6.semantic：能跑完但翻转 5/42（12%）**，其中 **4 条是 pro 判官判 arc_leak 被 flash 翻成 grounded**（漏检方向），1 条反向。判官漏检泄底 = 质量闸失效。
- **结论：判官节点（stage5.semantic / stage6.semantic）必须保留 pro+满思考。**

## 七、决策建议与整合清单

**按预注册决策规则逐条过闸**：

| 闸 | pro_think | flash_think |
|---|---|---|
| 成书（两本） | ✅ 2/2，残留 0，三查过 | ❌ 1/2（复核书 hook 三轮不过） |
| HARD 残留 | 0（hook_semantic_spoiler 属候选级不拦定稿） | 主样本 0；复核书终止 |
| 语义泄底（pro 判官口径） | 0 | 主样本 0（result_flashback）；候选级 4 条 arc_leak |
| 修复轮数 vs 基线 | 基线（主 2 复 3） | 主 3；复 ≥6 未收口 → **劣于基线** |
| 独有质量失误 | 无 | 写法词入计划 ×2、悬空姓氏 ×1、浅思考发作 ×3 |
| 兼任判官 | —（现任） | ❌（s5 四档全灭；s6 漏检 4 条泄底） |

**推荐：维持 `deepseek-v4-pro` + `DEEPSEEK_THINKING=on`（现状）为全局默认；不采纳 flash。**
理由：① flash 过不了质量闸（复核书未成书、判官不可用、修复轮数劣于基线）；② 每本约 $0.3-0.5 的生成差价（163 本语料全跑约省 $50-90）买不回额外修复轮次与「浅思考发作」的不可预期性；③ flash 也不更快。思考轴结论独立成立：`DEEPSEEK_THINKING` 默认 `on`（关思考双模型三轮全灭于 stage2.global）。

**盲读摘录**：`outputs/ab_model_20260815/blind_read_main.md`（主样本两臂成书 A/B 乱序：开篇文案 + 第 1/10/19 章，密钥在文末注释；复核样本只有 pro 成书，无对照不设盲读）。盲读结论不改变过闸判定，仅供人工感受两臂文风差异与终审确认。

**盲读结果与终审裁决（2026-08-15，如实记录）**：用户盲读偏好 **样本 A = flash_think**（n=1 本对照）。摊开身份与全部过闸数据后，用户终审裁决：**维持 pro+满思考全局（原推荐），不采纳 flash**——盲读文笔偏好不足以推翻复核书未成书、判官不可用、修复轮数劣于基线三条硬闸。该偏好留档：若日后 BE-08 归一化缺口修复且 flash 服务侧「浅思考发作」收敛，可凭本记录重开混搭评估（生成 flash + 判官 pro），无需重跑思考轴。

**整合清单（赢家=现任，零代码变更）**：
1. 本报告定稿落 `docs/`；
2. SKILL.md 追记一行：2026-08-15 模型×思考 A/B 复核维持 pro+满思考，判官节点永不换廉价模型，依据本报告；
3. 记忆更新：`project-novel-rewrite-scope` 的「锁定 deepseek-v4-pro」补上实验依据与日期；`DEEPSEEK_THINKING` 开关（默认 on）作为已落基础设施记录；
4. 待办登记（REQUIREMENTS 候选，本次不实现）：a) `LlmFailed` 应落 exit 2 而非 70；b) stage6.hook 段间归一化缺口（`hook_para_sep` 判据自述归一应修而未修，双模型 6 采样复现）；c) `--apply-edit` 相对路径按 cwd 解析与报错文案不一致；d) stage2.global 无定向付费重采样口（本实验以删臂缓存条目等价替代）。

**本实验总花费（账本事实合计，不含探针）**：生成+判官 真调用 pro_think 136 次 / flash_think 143 次 / nothink 两臂 6 次 / 判官一致性轮约 80 次；折算合计约 **USD 3.4**（四臂两书 + 判官一致性，当日平价上界）。
