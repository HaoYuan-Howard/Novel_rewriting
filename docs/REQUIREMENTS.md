### DEC-02 · 无可靠守卫的语义如何处置

以下能力目前不能被“加一条看起来合理的检查”草率关闭。每项要在“建立 ground truth 的守卫、
收走生成自由度、明确交人工、明确不可验证”中选一项：

- [ ] 写作拍严格按计划顺序落笔。
- [ ] prompt 不泄漏内部 beat / character / rule / node 标识。
- [ ] 计划不发明人物、事件和设定，重头稀缺，结尾钩子不提前泄底。
- [ ] 逐章抽取的施受关系、区间、硬数字、矛盾与非转抄质量。
- [ ] 全书规则/秘密收录标准及相关枚举的语义正确性。
- [ ] 文风画像的可迁移性、覆盖位置、区分度与素材分区。
- [ ] 写作不说破潜台词、遵守视角，开卷臂不过度照抄。
- [ ] 修剪不改变人物、地点、因果、时间与结尾立意。
- [ ] 开卷写手是否必须获得“现场 / 回忆 / 转述”的完整释义。
- [ ] 身份描述泄底、改写式泄底与设定块字面探针的判别力。
